# Number Guessing Game

The **Number Guessing Game** is a simple Python-based project in which the computer randomly selects a number between 1 and 100, and the player has to guess the correct number.

The program uses Python’s **Random module** to generate a random number. The player enters a guess, and the program gives a hint after each attempt. If the guessed number is smaller than the actual number, the program tells the player that the number is greater. If the guess is higher, it tells the player that the number is less.

The game continues until the player guesses the correct number. Once the correct number is guessed, the program displays a congratulatory message along with the total number of attempts taken.

### Objectives

* To understand the use of Python variables.
* To learn how to take input from the user.
* To use conditional statements such as `if`, `elif`, and `else`.
* To understand the use of loops.
* To learn how to generate random numbers using Python.
* To practice basic problem-solving and programming logic.

### Technologies Used

* **Programming Language:** Python
* **Module Used:** Random
* **Concepts:** Variables, Input/Output, Conditions, Loops, and Random Number Generation

### Conclusion

This project is a beginner-friendly Python game that helps demonstrate basic programming concepts in an interesting and interactive way. It also improves logical thinking and understanding of loops and conditional statements.
